# 수학격투: 곱셈 액션 배틀

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 구구단 격투 게임을 업그레이드했습니다.

- `index.html`: 업그레이드한 앱
  - 부스 도전: 이름을 적고 세 상대를 연달아 이겨 점수를 오늘의 랭킹에 올리기
  - 월드 정복: 6개 월드 60 스테이지, 별 모으기(이 기기에 저장)
  - 2인 대결: 화면을 반씩 나눠 동시에 대결, 선수마다 문제 수준 선택
- `board.js`: 부스 공용 랭킹(Firebase). 다른 부스 앱과 같은 파일
- `원본_학생작품.html`: 학생이 만든 원본
